
1. Instale as dependências:
   pip install -r requirements.txt

2. Inicie a API:
   python app.py

3. Abra suas páginas HTML normalmente no navegador.
   A API ficará em http://localhost:5000

O banco banco.db será criado automaticamente quando o app.py rodar.

Endpoints principais:
- POST /usuarios
- GET /comentarios
- POST /comentarios
- DELETE /comentarios/<id>
- GET /simulacoes
- POST /simulacoes
- GET /mensagens
- POST /mensagens
