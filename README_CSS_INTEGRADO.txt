Projeto Hungreless com CSS centralizado

Alterações feitas:
- Removidos blocos <style> das páginas HTML.
- Removidos styles inline principais dos componentes React.
- Criadas classes reutilizáveis no arquivo css/estilo.css.
- Mantida a integração com API Flask e banco SQLite.

Como rodar:
1. pip install -r requirements.txt
2. python app.py
3. Abra index.html ou perfil.html no navegador.

Observação:
As classes Bootstrap continuam sendo usadas para grid, cards e formulários, mas todo CSS customizado do projeto está centralizado em css/estilo.css.
